Résistance : les boutons

Trois façons de dessiner les boutons, sur la carte couchée retenue. Même moment du combat dans les trois : Isaure vient de se placer contre le Voleur. Sous chaque téléphone, une fenêtre de la forteresse avec les mêmes boutons. Les boutons réagissent au toucher.

ALa fenêtre GBA

Comme dans Fire Emblem sur Game Boy Advance : une fenêtre bleue à bord blanc, les actions en liste avec la petite main qui pointe, des boutons plats de la même famille.

Construire : Caserne ?

Le plus fidèle au jeu d'origine ; les actions se lisent comme un menu.

BGros boutons en relief

Des boutons pixel épais qui s'enfoncent au toucher, une couleur et une icône par action : rouge pour attaquer, vert pour les objets, bleu pour attendre.

Construire : Caserne ?

Le plus facile à viser au doigt ; Retraite devient un petit drapeau.

CFaçon appli

Les actions sont de grandes cartes qui disent ce qui va se passer ; en bas, une barre d'icônes rondes, le gros bouton orange pour finir le tour.

Construire : Caserne ?

Le plus moderne ; s'éloigne un peu du style GBA.

Quel que soit le choix, les mêmes boutons iront partout : combat, carte de campagne, forteresse, marchand, Intendance et fenêtres de confirmation. On peut aussi mélanger, par exemple les actions de C avec la barre de B.
