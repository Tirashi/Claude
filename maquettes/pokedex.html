Pokédex de poche · maquette 3

La liste en lignes de la maquette 2, retravaillée, et le même code habillé de trois façons. Il y a maintenant une barre de recherche (nom, numéro ou type), des filtres par type et une liste rangée par région. Les fiches ont un sprite fixe, avec les faiblesses et les résistances du Pokémon. L'onglet Types calcule le multiplicateur de dégâts : choisis le type de l'attaque, puis un ou deux types pour le Pokémon qui défend.

Descriptions écrites pour la maquette ; l'appli lira les descriptions officielles en français, les types et les évolutions sur PokéAPI, et les sprites sur son dépôt d'images.
