# Stratégie spatiale (nom provisoire) — notes pour Claude
Stratégie en temps réel avec pause, façon Stellaris, dans l'univers de Ciel de guerre. Cahier des charges : [`specs/strategie-ciel.md`](../specs/strategie-ciel.md). Démo sur l'accueil.
- **Scripts** (classiques, globaux partagés, dans cet ordre) : `shaders.js` (`window.SC_SHADERS`, planètes de Deep-Fold en GLSL, fabriqué par `outils/strategie-ciel/shaders.py`), `planetes.js` (`PlanetesDF.Planete`), `monde.js` (scène, SOL-7, planètes, ceinture, gisements `GIS`, portes, modèles `MOD`/`importe`, tirs, explosions), `unites.js` (`TYPES`, `U`, `S`, ordres, combat, minage, production, `VAGUES`), `interface.js` (caméra `CA`, pointeur, clavier, sélection, mini-carte, panneaux), `jeu.js` (états, boucle, record).
- **Modèles** : lus dans `../ciel-de-guerre/modeles/`, tourelles découpées d'après `../ciel-de-guerre/catalogue.js` (`decoupe` ; `equipe` pose tourelles et flammes) (pas dans `FILES` de `sw.js`) ; artefact : `window.SC_B64` (`python3 outils/strategie-ciel/artefact.py <sortie>`).
- **Perf** : planètes redessinées selon leur taille à l'écran (`majDecor`), 64 px au doigt (`DF_PX`) ; combat en pas fixes de 0,034 s (vitesse ×3 juste).
- **Tests** : `window.StrategieCiel` (`S`, `U()`, `jouer`, `produire`, `lancerVague`, `avance(s)`, `meurt`, `etat()`). `ETAT` vaut `charge` jusqu'à la fin du chargement des modèles. Test de fumée dans `outils/fumee.js`. Les `.glb` demandent `http://`.
- **Tuto** : `TUTO` dans `jeu.js` (étapes `fait()`, `S.tuto` gèle les vagues, `strategieciel.tuto`).
- **Pièges** : clic droit = ordre, clic droit glissé = pivoter ; au doigt, toucher un de ses vaisseaux le choisit, sinon c'est un ordre ; record `strategieciel.record` (transfert dans la fiche).
