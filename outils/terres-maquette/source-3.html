Terres franches · villageois et interface

Maquette 3 : la vallée de la direction B (Cute SCKR), au bourg. Les villageois sont tous différents (LPC : 24 personnes tirées au hasard parmi les peaux, têtes, coiffures, habits, tabliers, capuches et fichus), avec une hache ou une houe ; ils rapportent ce qu'ils récoltent au-dessus de la tête. Le bouton TS remet les villageois de Tiny Swords pour comparer. Les deux téléphones ne diffèrent que par l'habillage de l'interface.

Sources

Villageois : Universal LPC Spritesheet Character Generator (gratuit ; CC-BY-SA 3.0 / GPL 3.0, chaque auteur sera cité dans les crédits), composés par outils/terres-maquette/lpc-villageois.py. Icônes : Medieval Fantasy Icons, Pixel Medieval Fantasy Icon et Pixel Food Icon (lot Cute SCKR déjà acheté). Interface A : Fantasy UI de ToffeeCraft (version gratuite ; un « méga pack » payant existe). Interface B : Tiny Swords.
