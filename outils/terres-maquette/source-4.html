Terres franches · la vallée vivante

Maquette 4 : les animations ajoutées par le code aux images de Cute SCKR, avec l'interface Tiny Swords choisie. Les ailes du moulin tournent (découpées et reconstituées pixel par pixel), les arbres et le blé ondulent sous des rafales qui traversent la vallée, les champs poussent puis jaunissent, des feuilles tombent, des oiseaux et l'ombre des nuages passent, l'eau scintille, la fontaine coule. Le bouton ANIM coupe tout pour comparer.

Sources

Villageois : Universal LPC Spritesheet Character Generator (gratuit ; CC-BY-SA 3.0 / GPL 3.0, chaque auteur sera cité dans les crédits), composés par outils/terres-maquette/lpc-villageois.py. Icônes : Medieval Fantasy Icons, Pixel Medieval Fantasy Icon et Pixel Food Icon (lot Cute SCKR déjà acheté). Interface A : Fantasy UI de ToffeeCraft (version gratuite ; un « méga pack » payant existe). Interface B : Tiny Swords.
