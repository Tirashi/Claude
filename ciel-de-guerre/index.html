COMMANDES

TELEPHONE
Pose le pouce gauche n'importe où : un joystick apparaît (vers le haut : on monte). Boutons ronds à droite : FEU, MISSILE, LOOP, TONNEAU, et BOOST ou FREIN à garder appuyés.

PC, A LA SOURIS
Le curseur est ton viseur : les balles partent vers lui. Éloigne-le du centre de l'écran pour tourner, monter ou descendre ; au centre, l'appareil vole droit. Clic gauche : feu ; clic droit : missile. Z accélère, S freine, Q et D font un écart ; deux appuis rapides sur Z : looping, sur Q ou D : tonneau. Échap : pause.

PC, AU CLAVIER
Flèches : piloter. Espace : feu ; E : missile ; R : looping ; F : tonneau ; V : vue ; C : appareil suivant ; P : pause.

Le missile se verrouille sur la cible dans l'axe (cadre jaune puis LOCK). Les tourelles rouges des grands vaisseaux se détruisent aussi.
